# EventManager

A Spring Boot based Event Management application.

## Features

- Event registration
- User registration
- View registered users
- REST API using Spring Boot

## Technologies Used

- Java
- Spring Boot
- Maven
- HTML
- CSS
- Git
- GitHub

## How to Run

1. Open the project in VS Code.
2. Run the Spring Boot application.
3. Open `http://localhost:8080`.
